## Меню

Перенесено с фотографии прайса, висящего в кафе (есть в галерее Яндекса,
на сайте лежит как `assets/menu-photo.jpg`). Цены не менялись; изменена
только группировка по разделам для читаемости — например, «Котлета по-киевски»
в прайсе напечатана среди салатов, на сайте она во вторых блюдах.

Строка прайса «ВТОРОЕ 170 (120+50)» прочитана как «мясное блюдо 120 ₽ +
гарнир 50 ₽» — это сходится с отдельными строками «МЯСНЫЕ БЛЮДА 120» и
«ГАРНИР 50».

## Открытые вопросы к владельцу

1. **Часы работы.** Яндекс: ежедневно 8:00–18:00 — так и стоит на сайте.
   На табличке у входа (фото) написано: пн–пт 8:00–18:00, сб–вс 8:00–22:00.
   Что верно сейчас?
2. **Цена комплексного обеда.** В прайсе 250 ₽, на сайте тоже 250 ₽.
   В отзыве от 29.06.2026 упоминается 300 ₽. Нужна актуальная цена.
3. **Телефоны.** На табличке у входа есть ещё два мобильных:
   8-961-693-09-62 и 8-927-527-67-23. На сайт не выведены — добавить?
4. **Фото.** Взяты из галереи Яндекс Карт (снимки гостей). Если есть свои
   фотографии — заменим на них.
